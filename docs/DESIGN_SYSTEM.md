# 디자인 시스템

- 바탕 `#f6f7f1`, 카드 `#ffffff`, 기본 글자 `#252e28`, 강조 `#2b704f`.
- 부드러운 둥근 모서리, 충분한 여백, 명확한 입력 라벨을 사용한다.
- 목록은 한 열이며 좁은 화면에서는 좌우 여백을 줄인다.
- 입력 오류와 저장 실패는 `role=status` 영역에 표시한다. 버튼에는 텍스트 또는 접근 가능한 이름을 제공한다.
- 각 항목은 할 일 제목으로 라벨을 지정한 체크박스를 제공한다. 완료 항목은 체크 표시와 제목 취소선으로 구분한다.
- 체크박스의 키보드 포커스는 강조색 외곽선으로 표시하며, 완료 상태를 바꾼 뒤에도 같은 체크박스에 포커스를 유지한다.

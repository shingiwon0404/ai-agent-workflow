# 제품 요구사항

## 목표
사용자가 별도 계정 없이 작은 할 일 목록을 만들고 관리한다. AI 워크플로우는 독립된 개선 이슈를 설계 문서, 코드, 테스트, PR로 연결한다.

## 초기 범위
- 1~100자의 할 일을 추가하고 목록에서 삭제한다.
- 목록은 현재 브라우저의 localStorage에 남는다. 다른 기기와 동기화하지 않는다.
- 빈 목록, 잘못된 입력과 저장 실패를 사용자에게 알린다.
- 키보드와 모바일 화면에서 이용할 수 있다.

## 이후 시연
완료 표시 기능은 별도 이슈의 요구사항으로 추가한다. 초기 구현에는 포함하지 않는다.
